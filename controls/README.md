# Programmes de travail (catalogues de contrôles)

`<mission>.<langue>.json` est rédigé par Muse Spark au premier audit, puis réutilisé tant que le
référentiel ne change pas. Un auditeur le relit, le corrige si besoin et passe `"reviewed": true` :
le rapport l'indique alors comme « validé par un auditeur ». Versionné dans git = historique des revues.
