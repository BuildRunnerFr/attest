# Bibliothèque de scripts de test

Chaque script écrit par l'IA et exécuté avec succès est conservé ici (`<règle>-<empreinte>.py`).
Les audits suivants le rejouent tel quel : verdict reproductible, coût IA quasi nul (surveillance continue).
La revue de ces fichiers dans une pull request = validation des tests par un auditeur.
Un script n'est régénéré que s'il échoue ou si la définition du contrôle change.
